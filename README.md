# 🚀 Neural-Link Portfolio — Aditya Kumar Singh

🌐 **Live Portfolio:** https://neural-portfolio-v6pl.vercel.app/

A high-performance, futuristic developer portfolio built with a cyberpunk-inspired **Neural-Link interface**, showcasing full-stack development, AI/ML capabilities, and interactive UI engineering.

---

## ✨ Overview

This portfolio is designed to go beyond static presentation—delivering an **immersive, interactive experience** that reflects both technical depth and creative execution.

It combines modern frontend engineering with motion design to create a visually engaging, recruiter-ready portfolio.

---

## 🧠 Key Highlights

* **Neural-Link Hero System**
  Interactive SVG-based connection system linking dynamic skill nodes to the core profile

* **HUD Interface Layer**
  Real-time styled overlays with scan lines, orbit rings, and system-like UI elements

* **Project Dossiers**
  Projects presented as classified intelligence files with animated scan effects

* **Terminal Experience Section**
  Developer journey displayed as a terminal log with typewriter animation

* **Skills Matrix Visualization**
  Animated skill bars with neon glow and structured categorization

* **Custom Cursor System**
  Smooth dual-layer cursor enhancing interaction feedback

* **Floating Navigation Dock**
  Quick-access links to GitHub, LinkedIn, and contact channels

* **Optimized Performance**
  Built with smooth animations while maintaining responsiveness and fast load times

---

## 🛠️ Tech Stack

* **React 18** — Component-driven architecture
* **Tailwind CSS** — Scalable and modern UI styling
* **Framer Motion** — Advanced animations and transitions
* **Font Awesome** — Icon system
* **Google Fonts** — Syne, DM Sans, JetBrains Mono
